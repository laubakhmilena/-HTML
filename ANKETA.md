# Анкета участника курса по веб-разработке

`index.html` — учебная HTML-страница с описанием курса по веб-разработке и анкетой участника.

## Что есть на странице

- шапка сайта с заголовком и логотипом;
- навигация по разделам страницы;
- блок «О курсе»;
- блок «Преимущества курса»;
- блок «Направления обучения»;
- таблица с программой курса;
- форма анкеты участника;
- поля ввода, выпадающие списки, checkbox и radio-кнопки;
- кнопки отправки и очистки формы;
- подвал страницы.

## Используемые технологии

- HTML5;
- семантическая разметка;
- таблицы;
- формы;
- локальные изображения.

## Запуск

Откройте `index.html` в браузере.
