# Анкета участника курса по веб-разработке

`index.html` — учебная HTML-страница с описанием курса по веб-разработке и анкетой участника.

## Цель проекта

Показать базовую HTML-разметку на примере небольшой страницы: шапка, навигация, информационные разделы, таблица и форма для заполнения данных.

## Что есть на странице

- шапка сайта с заголовком и логотипом;
- навигация по разделам страницы;
- блок «О курсе»;
- блок «Преимущества курса»;
- блок «Направления обучения»;
- таблица с программой курса;
- форма анкеты участника;
- поля ввода, выпадающие списки, checkbox и radio-кнопки;
- кнопки отправки и очистки формы;
- подвал страницы.

## Используемые технологии

- HTML5;
- семантическая разметка;
- таблицы;
- формы;
- локальные изображения.

## Файлы проекта

```text
index.html   основная HTML-страница
ikonka.png   изображение/логотип
ANKETA.md    описание проекта
```

## Запуск

Откройте `index.html` в браузере или запустите папку через Live Server в VS Code.

## Что можно улучшить дальше

- Добавить отдельный файл `style.css`.
- Сделать адаптивное отображение на мобильных экранах.
- Проверить разметку через HTML-валидатор.
