# Анкета участника курса по веб-разработке

Учебный HTML-проект: страница с описанием курса по веб-разработке и анкетой участника.

## О проекте

Проект создан для практики базовой HTML-разметки. На странице есть шапка, навигация, разделы с описанием курса, преимущества, направления обучения, программа курса в таблице и форма анкеты для записи.

## Что есть на странице

* шапка сайта с заголовком и логотипом;
* навигация по разделам страницы;
* блок «О курсе»;
* блок «Преимущества курса»;
* блок «Направления обучения»;
* таблица с программой курса;
* анкета участника;
* поля ввода, выпадающие списки, checkbox и radio-кнопки;
* кнопки отправки и очистки формы;
* подвал страницы.

## Используемые технологии

* HTML5

CSS пока не используется. Проект подготовлен для дальнейшей стилизации.

## Структура проекта

```text
project/
├── index.html
├── ikonka.png
└── README.md
```

## Как открыть проект

1. Скачать или клонировать репозиторий.
2. Открыть файл `index.html` в браузере.

## Цель проекта

Научиться создавать правильную структуру HTML-страницы, работать с текстом, изображениями, ссылками, таблицами и формами.
