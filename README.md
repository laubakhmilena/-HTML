# HTML

Репозиторий с учебными работами по HTML. Файлы разложены по назначению: задания лежат в корне и идут по порядку, а итоговый сайт с анкетой вынесен в отдельную папку.

## Проект в папке `anketa-site/`

В папке `anketa-site/` находится отдельный учебный проект — сайт с анкетой участника курса по веб-разработке. Это готовая HTML-страница, на которой собраны описание курса, навигация, таблица программы и форма для заполнения анкеты.

В проект входит:

- `index.html` — основная страница сайта с разметкой анкеты, разделами курса, таблицей и формой;
- `ikonka.png` — изображение/логотип, который используется на странице;
- `ANKETA.md` — краткое описание проекта, его структуры и назначения.

## Задания

- `task-01.html` — задание 1.
- `task-02.html` — практика Emmet.
- `task-03.html` - `task-18.html` — последующие практические задания по HTML.
- `task-06.zip` — архив с материалами задания 6.

## Дополнительные материалы

## Как смотреть

Откройте нужный `.html` файл в браузере. Итоговый сайт находится в `anketa-site/index.html`.
