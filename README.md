# HTML

Репозиторий с учебными заданиями по HTML. Здесь собраны небольшие практические работы по базовой разметке, тегам, атрибутам, таблицам, ссылкам, изображениям и структуре страницы.

## Содержимое

- `task-*.html` — выполненные HTML-задания.
- `task-*` и `task-*_answer` — отдельные учебные материалы и ответы.
- `mockup` — файл/материал для работы с макетом.
- Изображения и архивы — дополнительные материалы к заданиям.

## Темы

- структура HTML-документа;
- текстовые теги и семантика;
- ссылки и изображения;
- таблицы;
- глобальные атрибуты;
- работа с учебными макетами и файлами.

## Как смотреть работы

Откройте нужный файл `task-*.html` в браузере. Для удобства можно использовать Live Server в VS Code.
