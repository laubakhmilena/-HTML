# HTML

Репозиторий с учебными работами по HTML. Файлы приведены к аккуратному виду: у каждого файла есть правильное расширение, а задания пронумерованы так, чтобы в GitHub они шли по порядку.

## Основные файлы

- `index.html` — итоговая страница с анкетой участника курса по веб-разработке.
- `ANKETA.md` — краткое описание итоговой страницы `index.html`.
- `ikonka.png` — иконка/логотип для страницы анкеты.
- `mockup.jpg` — макет для учебной работы.
- `task-06.zip` — архив с материалами задания 6.

## Задания

- `task-01.html` — исходный вариант задания 1.
- `task-01-answer.html` — исправленный вариант задания 1.
- `task-02.html` — практика Emmet.
- `task-03.html` - `task-18.html` — последующие практические задания по HTML.

## Дополнительные материалы

- `example-test-03.jpg` — пример для теста 3.
- `result-test-03.png` — результат теста 3.

## Как смотреть

Откройте нужный `.html` файл в браузере. Для удобной проверки можно использовать Live Server в VS Code.
