# HTML Portfolio

Учебный репозиторий с практическими работами по HTML. Он показывает базовые навыки верстки: структуру HTML-документа, семантические теги, таблицы, формы, изображения, ссылки и работу с учебными макетами.

## Цель репозитория

Собрать в одном месте выполненные задания по HTML и отдельный небольшой проект, который можно показать как часть портфолио начинающего веб-разработчика.

## Проект `anketa-site/`

В папке `anketa-site/` находится учебный сайт с анкетой участника курса по веб-разработке.

В проект входит:

- `index.html` — основная страница сайта с шапкой, навигацией, описанием курса, таблицей программы и формой анкеты;
- `ikonka.png` — изображение/логотип, который используется на странице;
- `ANKETA.md` — краткое описание проекта, его структуры и назначения.

## Что сделано

- Выполнены практические HTML-задания `task-01.html` - `task-18.html`.
- Файлы переименованы так, чтобы задания шли по порядку в GitHub.
- Для файлов указаны понятные расширения: `.html`, `.jpg`, `.png`, `.zip`, `.md`.
- Итоговый сайт вынесен в отдельную папку `anketa-site/`.
- Добавлены README и CHANGELOG для понятной навигации по репозиторию.

## Как запустить

1. Откройте репозиторий в браузере или скачайте его на компьютер.
2. Для просмотра итогового сайта откройте `anketa-site/index.html`.
3. Для просмотра заданий откройте нужный файл `task-*.html`.

Можно использовать Live Server в VS Code, чтобы удобнее проверять HTML-страницы.
